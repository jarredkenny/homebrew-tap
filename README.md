# jarredkenny/homebrew-tap

Homebrew formulae for [jmux](https://github.com/jarredkenny/jmux) — the terminal
workspace for agentic development.

```bash
brew install jarredkenny/tap/jmux
```

jmux requires tmux 3.2+, which this formula installs for you. The binary is
self-contained: no Bun or Node runtime is needed.

Formulae here are updated automatically by jmux's release script; please open
issues against [jarredkenny/jmux](https://github.com/jarredkenny/jmux/issues).
